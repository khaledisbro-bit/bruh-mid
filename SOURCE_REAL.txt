THE ONE THING THE BYTES DO NOT HOLD

Function 2.1 carries a packed function of 393 bytes under the salt
proto:p.2.1e1. Its key is a string the program computes and compares, and the
file keeps only a digest of that string - slot 16,
b5c89049c27bb0cc3a5e3b62e506a436cd38155e1b63a640f0d573d889c77235. A digest
cannot be read backwards, so that string has to be offered from outside and the
file's tag answers yes or no in one step. real.lua takes candidates for it in
MATERIALS, and that list is empty.
